# FigureCard

A quiet bordered panel for one comparison: bold title with a tiny mono `PNG` export tag, a muted one-line subtitle, paired bars, a two-item legend, and a mono `FIG A` label with a caption that states the takeaway in one sentence.

The consumer provides the title, subtitle, the bar groups (each a bold name, a baseline value and a subject value), the legend and the takeaway sentence. Baseline bars use `stroke`, the subject bar uses `text` (not orange: `signal` means state). Value labels sit at the bar ends; there are no gridlines or axes; only the key number is bold. Uses: candidate versus leader, validation versus test, trial N versus N-1. Development evidence keeps its 'development' tag in the subtitle or caption. A delta in the caption is a focal number: it takes the sign role (option C) with a leading + or minus glyph, following the Settings convention (default red up / green down, see SignConventionSetting); bar values and all other numbers stay neutral. `preview.html` shows both conventions; `preview-considered.html` keeps the rejected options. Structure borrowed from the Anthropic code-review blog figures (patterns only). States: default, loading, empty (StateBlock inside the body), hidden test split (value cell shows "Hidden", no bar).
