# SignConventionSetting

The Settings-page row that flips the up/down colour convention. Decided by the owner: the convention is a SETTING with the default red up / green down (A-share convention); the switch flips it to green up / red down.

Spec: one row under a Settings group heading. Label "Price colours", `SegmentedToggle` with two options, "Red up, green down" (default, selected on first run) and "Green up, red down". One sentence under the row: "Changes colours only. Numbers, signs and exports stay the same." The choice is a per-user preference, applied at once with no reload and no confirm, and set as `data-sign-convention="red-up" | "green-up"` on the document root, which re-maps `sign-positive` and `sign-negative` (see bundle.css). The switch changes presentation only, never data: values, the + and minus glyphs, copied text, exports and API payloads are identical in both settings; neutral statistics and state colour (`signal`) are unaffected. Keyboard: arrow keys move, space or enter selects. States: default, focus, disabled (read-only session: the control stays visible with the reason line).
